    How it works

    • Before you start. Open the file in Chrome or Edge on a laptop. Press Allow the microphone, then choose Allow when the browser asks. If the browser is set to block microphones, it will not ask: the app then tells you which setting to change.
    • Record. Type the name. Press Start recording. Press Stop and keep at the end. The recording is linked to that name.
    • Retry. Clear / Reset Recording deletes the audio and both transcripts at once. An Undo button shows for a few seconds in case you press it by mistake.
    • Who is speaking. These are role plays, so the recording has two voices. Tap Student or Teacher while you record and each new line starts with S: or T:. After Transcribe the recording, use the Mark line buttons to label each line. Only the student's lines are evaluated.
    • Edit. Fix the English box first. The IPA box follows it. Once you type in the IPA box, it stops updating so your edits are safe. Rebuild IPA from English starts it again.
    • Evaluate and mark. Evaluate Speech looks for greetings, linking words, sequence words, modals, polite language, opinions and repeated ideas. It suggests a level for each criterion. Your choice always wins.
    • Report. Print Student Report gives a one-page A4 card. Choose Save as PDF in the print window for a PDF copy.
    • Save. Save Locally to Device downloads a ZIP with the audio and a text report. Nothing is uploaded anywhere.
    • Next student. The list on the left keeps every student for this session. Tap a name to go back to it. Closing the tab clears the list, so save first.

    What needs the internet

    • Recording, playback, IPA, marking, printing and saving all work with no internet.
    • Transcribe the recording runs a speech model inside this browser. It needs the internet the first time only, to download the model (about 40 to 80 MB). After that the browser keeps it.
    • Live transcription is a browser service. Chrome and Edge send the sound to their own speech service, so live transcription needs the internet there. Safari on a Mac may work offline. Firefox has no live transcription. With no transcription you can type the English yourself while you play the recording back.
    • On an iPad or iPhone the microphone only works when the file is opened from a website (https). A file opened from the Files app cannot record.
